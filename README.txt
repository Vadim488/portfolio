ПОРТФОЛИО ТЕРЕХОВА ВАДИМА АЛЕКСЕЕВИЧА

Как открыть:
1. Распакуйте архив в отдельную папку.
2. Откройте папку в Visual Studio Code.
3. Откройте index.html в браузере.
   Удобнее всего установить расширение Live Server в VS Code,
   нажать правой кнопкой по index.html и выбрать "Open with Live Server".

Файлы:
- index.html — структура и тексты сайта.
- style.css — оформление и адаптивный дизайн.
- script.js — мобильное меню и анимации.

Что нужно персонализировать:
- В index.html замените ссылки-заглушки на свой Email, Telegram и GitHub.
- При желании добавьте фотографии/скриншоты проектов и ссылки на них.
- Проверьте формулировки и оставьте только те технологии и функции,
  которыми действительно владеете.

Сайт сделан на HTML, CSS и JavaScript без сборщика и дополнительных зависимостей.
Для шрифта Manrope при подключении к интернету используется Google Fonts;
при отсутствии интернета будет использован системный шрифт.

В разделе «Проекты» добавлены: «Здоровье+» (Flask), фронтенд-версия «Здоровье+» и платформа «Обменяй меня» (Flask).
